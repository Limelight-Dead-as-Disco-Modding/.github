## WELCOME TO THE LIMELIGHT FAMILY

Limelight started as a mod manager and somehow grew into an entire family of
increasingly questionable ideas.

The goal is simple: make *Dead as Disco* modding feel like opening an app, not
fighting with folders, command windows and tools that were never made for the
 community.

Whether you want to manage character mods, switch models while the game is
running, build a custom arena or help us experiment with multiplayer, there is
now a place for it under Limelight.

## THE FAMILY

### [LIMELIGHT](https://github.com/Limelight-Dead-as-Disco-Modding/Limelight)

The main mod manager and launcher. Import and organise character mods, create
profiles, launch the game and use the Live Loader to switch supported models
without restarting *Dead as Disco*.

### [LIMELIGHT ARENAKIT](https://github.com/Limelight-Dead-as-Disco-Modding/LimelightArenaKit)

**Your arenas. Your stage.**

Arena modding stopped working, so we brought it back. ArenaKit gives creators a
visual route for making new arenas, bringing older editable projects forward,
building them and packaging the finished mod for the current game.

### [LIMELIGHTMP](https://github.com/Limelight-Dead-as-Disco-Modding/LimelightMP)

The experimental multiplayer side of the family. Two players, two copies of
the game and a growing pile of very strange networking problems. It is early,
it is experimental, and it is already doing things *Dead as Disco* was never
supposed to do.

### [LIMELIGHT NATIVE BRIDGE](https://github.com/Limelight-Dead-as-Disco-Modding/LimelightNativeBridge)

The behind-the-scenes runtime companion used by Limelight's live features. Most
players will never need to touch it directly, which is exactly how we want it.

### [LIMELIGHT DOCUMENTATION](https://github.com/Limelight-Dead-as-Disco-Modding/LimelightWiki)

The home for setup guides, compatibility notes, troubleshooting, ArenaKit
authoring help and the development journey behind the whole project.

## WHERE DO I START?

If you just want to use mods, start with
[Limelight](https://github.com/Limelight-Dead-as-Disco-Modding/Limelight/releases).

If you want to create an arena, start with
[ArenaKit](https://github.com/Limelight-Dead-as-Disco-Modding/LimelightArenaKit).

If something has gone wrong, or you just want to know how any of this works,
open the [Limelight documentation](https://limelight-dead-as-disco-modding.github.io/LimelightWiki/).

## HELP US BUILD IT

Limelight is built in public for the *Dead as Disco* modding community. Bug
reports, testing, ideas, documentation fixes and contributions are all welcome.

Use the issue tracker belonging to the project you are having trouble with and
include as much useful detail as you can. Please do not post private files,
personal credentials or unrelated crash data in a public report.

## IMPORTANT

- Only share content that you have permission to share.
- Do not redistribute extracted game assets, Unreal Engine files or private
  source code.
- Expect experimental features to break while they are being developed.
- A future game update may require compatibility work across the family.

Limelight is a community project. It is not affiliated with or endorsed by
Brain Jar Games or Epic Games.
